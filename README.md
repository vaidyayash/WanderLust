# WanderLust

WanderLust is a full-stack property rental and booking web application inspired by Airbnb.

## Tech Stack
- Backend: Node.js, Express
- Database: MongoDB
- Templating: EJS
- Styling: CSS
- Authentication: (to be added / if added)

## Features
- View property listings
- Create new listings
- Edit and delete listings
- Server-side rendered pages
